# zzy420328.github.io

张子悦的个人简历网站，用于 GitHub Pages 展示。

## 页面结构

- `index.html`：教育背景
- `internship.html`：实习经历
- `projects.html`：项目经历，采用纵向宽卡片展示钙循环碳捕集、固体吸附材料研发与电池热管理三个项目。每个项目按「项目简介」「我的主要工作」「成果」组织；内容与布局同步维护至 `resume-all-in-one.html`。
- `awards.html`：奖项和竞赛
- `styles.css`：全站样式

## 放置个人照片

将个人照片保存为：

```text
assets/profile.jpg
```

建议使用竖版证件照或形象照，网页会自动裁切为小尺寸头像区域。

## GitHub Pages 部署

1. 在 GitHub 创建仓库：`zzy420328.github.io`
2. 将本文件夹内所有文件上传到该仓库根目录。
3. 打开仓库的 Settings > Pages。
4. Source 选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/root`。
6. 保存后访问：`https://zzy420328.github.io`
